# HealthGenie AI

HealthGenie AI is a web application that helps users analyze their symptoms and provides personalized treatment recommendations. 
It also allows users to upload images for analysis.

# Features
- **Symptom Analysis**: Analyze symptoms and receive personalized treatment recommendations.
- **Image Upload and Analysis**: Upload images for advanced symptom analysis.
- **Responsive Design**: A user-friendly interface that works seamlessly across devices.

# Technologies Used

- **Python**: The main programming language used for the backend.
- **Flask**: A lightweight WSGI web application framework used to build the web application.
- **HTML**: Used for structuring the web pages.
- **CSS**: Used for styling the web pages.
- **JavaScript**: Used for adding interactivity to the web pages.
- **SQLAlchemy**: An SQL toolkit and Object-Relational Mapping (ORM) library for Python, used for database interactions.
- **Jinja2**: A templating engine for Python, used to render HTML templates.
